## Known bugs to fix (from gap analysis)
- Build hash caching silently disabled when git ls-remote fails — add fallback
- Single agent token has no security isolation — add per-job scoped tokens (S-02)
- Logs are ephemeral (in-memory) — persist to disk or DB
- No container cleanup on rollback — leaks stopped containers over time
- Domain routing is .localhost only — needs real DNS + TLS for production
- No TLS/SSL — Caddy config generates HTTP-only routes
- env discovery is GitHub-only — GitLab/Gitea/Bitbucket return empty silently
